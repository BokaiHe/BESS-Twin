# 仿真规格与第一阶段验收

## 拓扑

外部 110 kV 电网 ↔ 并网主变 110/35 kV ↔ 35 kV 汇集母线。

光伏、三台风机及四个 BESS 单元各自通过等效升压接入 35 kV 母线。母线经 35/10 kV 园区配电向工业用户供电，并通过 10/0.4 kV 变压器供应居民与充电设施。升压设备在发电/储能节点中等效表达。

高压塔和架空导线只在外部电网至并网主变段出现。地面支路表示等效配电电缆路径，非真实电缆施工位置。第一阶段没有交流潮流求解，额定参数是演示有功限制，不能作为电气设备选型依据。

## 容量及负荷

| 项目            | 参数                                         |
| --------------- | -------------------------------------------- |
| 光伏直流 / 交流 | 20 MWp / 16 MWac，容配比 1.25                |
| 风机            | 3 × 4 MW                                     |
| BESS            | 4 × 2.5 MW / 5 MWh                           |
| SOC             | 初始约 15%（稳态求解），下限 10%，上限 90%   |
| 效率            | 充电 95%，放电 95%（电池能量侧与交流侧之间） |
| 并网            | 购电、上网分别限制 15 MW                     |
| 负荷            | 工厂 11:00 峰值 14 MW；居民 19:00 峰值 5 MW  |

负荷按小时锚点线性插值，全天合计峰值小于理论上限 19 MW。阴天晚峰风光减少，无储能基准产生缺口，加入储能后供电完整；不是随机碰巧产生的缺口。

光伏 DC→AC 在容量裁剪前暂按理想转换建模，不单独加入光伏逆变效率；电池效率实际进入积分。晴天 12:00 直流可用功率 19.6 MW，交流 16 MW，削顶 3.6 MW。PV clipping 与并网受限弃电分别记录，功率守恒使用实际交流出力。

## 时间与确定性

每个剧本一次计算 00:00–23:59 共 1,440 个一分钟区间。`minute = m` 表示区间 `[m, m+1)`；Snapshot 的 SOC 和累计费用是该区间起点状态，功率是该区间的恒定调度功率。

每个电池节点同时携带 `nextSocPct` 用于验证积分。下一帧 `socPct` 等于上一帧 `nextSocPct`。当天最后一分钟积分后的完整电量与费用在 `day.summary`；23:59 卡片的累计费用尚不含最后一分钟，符合区间起点口径。

图表保留每一分钟的数据，功率采用后阶梯线表示区间恒值，SOC 采用线性连接；故障跳变仅发生在事件分钟。点击绘图区按横坐标换算分钟，滑块支持键盘选择。

所有快照递归冻结。源适配器按剧本缓存；seek 仅按下标读不可变数组。渲染帧/粒子动画不更新物理状态。没有随机数，也没有依赖当前系统时间的物理计算。

## 调度

已知全天气象与负荷（演示用完美预测）；设备故障不可预知。

1. **并网削峰**：净负荷超过 15 MW 时储能先放电，可动用削峰预留。
2. **风光消纳**：风光富余优先充电；储能满后在 15 MW 内上网，再超出才按比例限发。
3. **备能充电**：在谷时与平时，计算下一个（谷时为全部剩余）峰段在规划水位下所需电量，加上之后的削峰预留与 1 MWh 缓冲，**先扣除峰段前预计可免费获得的风光富余**，只从电网补差额。充电尽早进行，不超过 4 MW 且不突破购电上限。因此晴天夜间不从电网充电（白天光伏会充满），阴天在谷时充到约 90%。
4. **峰时放电**：把购电压平到规划水位 L，只使用削峰预留以上的电量。
5. **规划水位 L**：从当前状态向后完整模拟，用二分搜索找出全天每个峰段都能守住的最低 L。故障发生时以剩余在线单元重新规划。
6. 功率按单元可用能力比例分配；若购电与储能均不足，记录未供负荷，绝不突破并网限制。

**周期稳态**：晴天与阴天剧本先迭代求出“00:00 电量 = 24:00 电量”的起始 SOC（晴天与阴天均约 15%），故障日沿用晴天的起始状态，保证故障前逐分钟一致。

| 剧本       | 规划购电水位  | 关键行为                                                        |
| ---------- | ------------- | --------------------------------------------------------------- |
| 晴天典型日 | 9.0 MW        | 08:42–13:41 光伏充电至 90%；17:00–20:41 放电，购电稳定在 9.0 MW |
| 阴天风弱日 | 10.6 MW       | 00:00–03:57 谷时充电至约 90%；晚峰放电并防止购电越限            |
| 储能故障日 | 9.0 → 10.2 MW | 17:05 起 BESS-04 升温预警，17:30 离线并重新规划                 |

## 故障

17:05 起 BESS-04 温度上升（演示热模型），超过 45 °C 产生预警；17:30 过温保护离线，当天不恢复。故障前气象、负荷、调度和 SOC 与晴天一致。故障后其功率为零，电量冻结；剩余三台的功率额定上限 7.5 MW、容量 15 MWh，实际能力仍受 SOC 约束。

总 SOC 继续按全部安装容量 20 MWh 计算，包含离线单元冻结电量；右侧另外显示在线单元 SOC。虚线基准与实线使用同一 SOC 分母，避免故障时分母改变制造假跳变。

## 电价与费用

谷 00:00–07:00：0.35；平 07:00–10:00、12:00–17:00、21:00–24:00：0.68；峰 10:00–12:00、17:00–21:00：1.08 元/kWh。上网 0.28 元/kWh。全部为示例。

按分钟积分 `(购电MW × 购电单价 − 上网MW × 上网单价) × 1000 / 60`。

无储能基准共享发电、负荷、电价和并网约束；一旦基准截至当前产生未供电量，`estimatedSavingsCny` 为 null。晴天与阴天为周期稳态，全天合计不含电池存量变化；故障日沿用晴天初始电量，但期末电量不同，需同时显示电量变化与离线冻结电量，账单不对存量变化估值。不可比时仅显示账单差额，不显示节省率；导出报告的 `daySavingsCny` 为 null，原始差额独立保存在 `billDifferenceCny`。日内数值另由 `storedDeltaMWh` 给出“已储存待用”的电量。不是真实账单或投资收益。

## 验收

`npm test` 逐分钟检验全局与每个拓扑节点的功率守恒、单元 SOC 边界与效率积分、双向并网限制、支路/机组限制、无相反流同时发生、削峰预留、无未供负荷、费用积分、故障隔离及同时间查询一致性。

`npm run test:e2e` 检验卡片与引擎数值一致、时间回放、故障基准双虚线、告警定位、搜索设备、曲线收起展开、回放终点重启及移动端无水平溢出。
